## 🧠 Engineering Principles

**Defensive by design**  
Parameterized queries, explicit authentication boundaries and controlled data access.

**Contract-first APIs**  
OpenAPI specifications and Swagger documentation make backend interfaces explicit and testable.

**Reproducible environments**  
Docker and Docker Compose provide repeatable application and database environments.

**Controlled AI**  
AI handles language understanding and generation where appropriate. Business rules, validation and sensitive decisions remain under deterministic software or human control.

**Evidence before positioning**  
I distinguish between capabilities I have demonstrated, capabilities I am actively developing, and capabilities I plan to build next.
